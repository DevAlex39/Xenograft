# SFX — Menu principal

Prompts pour outil de génération audio par IA (type ElevenLabs Sound Effects, Stable Audio). Style cohérent avec la DA du menu : dark fantasy, forêt mystique, parchemin usé, ambiance médiévale feutrée.

## 1. Survol de bouton (hover)

**Durée** : ~0.3-0.5s, son court et discret

```
A subtle, soft magical whoosh sound for a UI button hover, low-pitched
gentle shimmer, faint mystical chime undertone, short and understated,
dark fantasy game menu style, not intrusive, warm and inviting tone
matching an ancient parchment/forest aesthetic.
```

## 2. Clic de bouton

**Durée** : ~0.3-0.6s

```
A satisfying UI button click sound with a subtle wooden/parchment
texture, low thud combined with a soft magical resonance, medieval
fantasy game menu style, confident and weighty but not harsh, short
decay.
```

## 3. Crépitement de feu (boucle continue)

**Durée** : 5-10s, doit boucler proprement (début/fin raccordables sans coupure audible)

```
A cozy campfire crackling loop, warm wood fire sound with occasional
soft pops and embers crackling, seamless loop point, ambient and
continuous, medium-low volume presence suitable as background ambiance
for a dark fantasy forest menu screen, no wind or other environmental
noise mixed in.
```

## 4. Fanfare pour le bouton mute (activation/désactivation son)

**Durée** : ~1.5-2.5s

```
A short medieval trumpet fanfare, 2-3 notes, warm brass tone with a
slight reverb suggesting a stone hall or open forest clearing, heroic
but brief and understated (not bombastic), fits a dark fantasy
painterly game menu, similar in weight to a small achievement or
toggle confirmation sound rather than a grand victory theme.
```

## Note d'intégration
Une fois générés, les fichiers devront être intégrés en base64 dans `xenograft-main-menu.html` (même logique que les images) pour garder le fichier auto-contenu, cohérent avec le reste des assets.
